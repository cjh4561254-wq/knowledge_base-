# 前端重塑 Demo · 公共设计契约（所有子智能体必读，逐条遵守）

## 0. 铁律
1. **绝对不许修改任何业务代码**：`web/page/*`、`web/api/*`、`utils/*`、`config/*`、`processor/*`、`.env` 一律只读。
   你只能在自己的那**一个**目标文件里写代码（路径见任务分配）。
2. 产物必须是**纯静态单文件 Demo**：内联 CSS + 内联 JS，**零外部资源**——禁止 CDN、禁止 Google Fonts / 任何网络字体、
   禁止外链图片。图标一律**内联 SVG**（不许用 emoji 当图标，除非风格本身要求）。字体用系统栈（`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`）。
3. **不联网、不调后端**：所有数据用下面第 3 节的 Mock，写死在文件里。
4. 必须能**单独打开**（`file://` 直接双击也能看），同时能被大厅用 iframe 嵌入。
5. 本机预览浏览器**没有 GPU 加速**：毛玻璃/大面积 `backdrop-filter`、长列表阴影、持续动画会掉帧。
   允许毛玻璃，但**只用在 1~2 个局部层面**（如顶栏或登录卡片），不要整页糊；动画时长 ≤400ms，`prefers-reduced-motion` 要能关。

## 2. 现有真实页面的模块骨架（Demo 必须覆盖，缺一不可）
下面是从真实项目里提取的结构，**保留同样的信息层级**，视觉与布局按你的风格自由发挥。

### 2.1 Chat 主模块（真实页面 `web/page/chat.html` 的等价结构）
- **顶栏**：品牌名 `BOSS智库知识库` + 在线状态点与文案（`在线 · 可查询知识库与联网信息`）+ `流式输出`开关（checkbox）+ `清空对话`按钮。
- **消息流**：
  - 用户消息气泡 + 时间（如 `20:23`）；
  - 机器人消息：头像 + `BOSS智库` 名称 + **答案正文**（含上标引用角标 `2`/`3`/`5`，视觉上是小圆角 sup chip）；
  - **参考来源列表**（标题「参考来源（8）」）：每条含 `[编号]`、标题、`知识库`/`联网` 标签、`chunk_id=…` 或外链、`相关度 0.9xxx`；
  - **引用图片区**：4 张缩略图（用内联 SVG 占位图，标注 `参考图片`）；
  - **阶段进度折叠面板**：`阶段进度（已完成7，进行中0，状态：已完成）` + ✅ 节点清单（节点名见第 3 节）；
  - 一条**追问示例**：`您是想问以下哪个产品：HAK180、Hak180、Coze 工作流实战:商家客服初级？请明确一下型号。` + 可点击的**型号候选 chips**。
- **输入区 composer**：多行输入框（placeholder `请输入问题（Enter 发送，Shift+Enter 换行）`）+ 发送按钮 + 快捷键提示（`Enter 发送`、`Shift+Enter 换行`）。
- **欢迎语**：`你好，我是BOSS智库知识库客服。你可以直接提问，我会在"阶段进度"里展示处理过程。` + 提示 `可以问"如何使用万用表测量电压？"`。

### 2.2 导入主模块（真实页面 `web/page/import.html` 的等价结构）
- **拖拽上传区**：`点击或拖拽文件到此处 (PDF/MD)` + 上传图标。
- **文件列表**（3 条，含不同状态以展示层级）：
  - `03-商家客服初级.pdf` `1.7 MB` → 已完成，进度条 100%，`切片数：17`，结果链接 `查看Markdown` / `下载Markdown`；
  - `sample.pdf` `0.7 KB` → 已完成，`切片数：1`；
  - `损坏文件.pdf` `2.3 MB` → 失败态，错误文案 `PDF 加密或无法解析，已中止导入`（必须醒目且不破坏布局）。
- **节点执行日志**（可折叠）：中文节点名 + 耗时，例如 `PDF转Markdown 33.59s`、`Markdown图片处理 943.98s`、`向量生成 72.58s`、`导入向量库 5.39s`。
- **状态徽章**：上传中 / 处理中 / 已完成 / 失败 四态都要出现。
- **后端地址提示**：`后端接口地址：http://127.0.0.1:8000`。

### 2.3 登录模块（全新功能，每套都要设计）
- 品牌区（logo + `BOSS智库知识库` + 一句副标题）；
- **账号**输入（placeholder `手机号 / 邮箱 / 用户名`）、**密码**输入（含显示/隐藏切换）；
- **记住我**（checkbox）+ **忘记密码**（链接）；
- 主 CTA `登录` 按钮（含 hover/focus/active/disabled/loading 态，至少实现 hover 与 focus）；
- 分隔线 + **第三方登录图标**：企业微信、钉钉、飞书、GitHub（内联 SVG，图形可抽象但要可辨识，带 `aria-label`）；
- 底部版权 `© 2026 BOSS智库 · 企业级智能知识库系统`；
- **表单校验错误态**：用静态展示一条错误（如 `用户名或密码错误`）+ 输入框错误描边与提示文字；
- 符合该大厂风格的**背景视觉**（渐变/网格/大图/留白/霓虹等，按风格自由发挥，但必须离线内联实现）。

## 4. 质量门槛（交付前自查，报告里要给数字）
- 响应式：`1440`、`1024`、`768`、`390` 四档不破版、不横向滚动、导航可用。
- 无障碍：可聚焦元素有可见 focus 环；图标按钮有 `aria-label`；正文对比度 ≥ WCAG AA（4.5:1）；`<html lang="zh-CN">`。
- 交互至少 2 处真实可用（不能只是静态图）：例如 Chat/导入 Tab 切换、阶段进度折叠、引用角标点击滚动定位、
  密码显隐、记住我勾选态、发送后**模拟流式追加**（`setTimeout` 逐段吐字即可，禁止真实网络）。
- 无 JS 报错：控制台必须干净（大厅用 iframe 嵌你，报错会影响检视）。
- 文件大小合理：单文件 ≤ 120KB（内联资源别塞 base64 大图）。
